# 受診前整理シート

受診や相談の前に、選ぶだけで5つの質問に答えると、医師に見せられる「A4・1枚のシート」と、口頭で伝える「カンペ」ができるWebアプリです。

- データベース・サーバー不要の静的Webアプリ（React + Vite + TypeScript）
- 入力内容・いつものお薬・保存した記録は、すべて **この端末のブラウザ（localStorage）の中だけ** に保存します。外部への通信・送信はしません。
- 見本の受診ケース（架空・3種類）は、保存されません。自分の記録には影響しません。
- 診断や治療の判断をするものではなく、診察で伝えるためのメモを整えるものです。

## 使い方

1. 「新しく始める」から、5ステップ（伝えたいこと／いつから／全体の様子／お薬／聞きたいこと）に答えます。
2. 結果画面で、「カンペ」（口で伝える）と「シート」（医師に見せる）を切り替えます。
3. 「A4で印刷・PDF保存」で、A4・1枚に印刷またはPDF保存できます。

## 開発

```
npm install
npm run dev          # 開発用
npm run build:pages  # docs/ に公開用を作る（GitHub Pages: main の /docs）
```
